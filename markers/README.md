# markers/ overview

Marker-specific embryo assessment workflows.

Included subareas:

- `blastocyst_grading/`
- `blastocyst_segmentation/`
- `fragmentation/`
- `cell_count/`
- `stage_classification/`
- `quality/`

Top-level scripts (for cross-method analyses) include:

- `evaluate_multitask.py`
- `compare_methods.py`
- `visualize_methods.py`

Refer to each marker subdirectory README for task-specific details.
