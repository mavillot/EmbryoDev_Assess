# assessment/ overview

Main research workflows live in this directory.

- `MultiTask/`: joint multi-task pipeline (segmentation + classification + optional temporal branch).
- `embryo_utils/`: reusable embryo image/video utilities used by multiple workflows.
- `ploidIA/`: ploidy-oriented pipelines (3D CNN, feature-based ML, consistency studies).
- `vIAbility/`: viability-oriented pipelines (3D CNN, multimodal, tabular, feature extraction).

For first use, start with `MultiTask` and the root README commands.
