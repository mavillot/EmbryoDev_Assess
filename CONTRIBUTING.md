# Contributing

Thanks for contributing to EmbryoDev_Assess.

## How to contribute

1. Open an issue describing the bug, documentation gap, or research improvement.
2. Keep pull requests focused and small.
3. Avoid committing datasets, model checkpoints, notebook outputs, or other large generated files.
4. Document any behavior-impacting changes and assumptions about dataset layout.
5. Include reproduction steps for fixes when possible.

## Code/documentation expectations

- Preserve research intent and avoid unverified claims.
- Keep commands in docs aligned with actual script interfaces.
- Prefer clear docstrings/comments for non-obvious data conventions.

## Reporting problems

Use GitHub Issues for bugs and reproducibility blockers.
For security concerns, follow `SECURITY.md`.
